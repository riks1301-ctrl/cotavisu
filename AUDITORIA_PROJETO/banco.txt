MODELAGEM DO BANCO DE DADOS — CotaVisu
Supabase (PostgreSQL) — Projeto: Connect CV
==================================================

=== TABELAS ===

──────────────────────────────────────────────────
1. service_categories
──────────────────────────────────────────────────
id            UUID PK default gen_random_uuid()
name          VARCHAR(100) NOT NULL
slug          VARCHAR(100) UNIQUE NOT NULL
icon          VARCHAR(10)
color_hex     CHAR(7)
sort_order    SMALLINT default 0
is_active     BOOLEAN default true
created_at    TIMESTAMPTZ default now()

Dados seed: 6 categorias (Adesivos, Banners e Lonas, Fachadas e ACM,
            Plotagem e Recorte, Luminosos e Letras, Impressão Digital)

──────────────────────────────────────────────────
2. standard_services  (modo prateleira)
──────────────────────────────────────────────────
id            UUID PK
category_id   UUID FK → service_categories.id
name          VARCHAR(150) NOT NULL
description   TEXT
unit          ENUM('m2','unit','linear_meter') default 'm2'
base_price    DECIMAL(10,2) NOT NULL
avg_days      SMALLINT default 3
formula_type  ENUM('area','unit','area_min1m2') default 'area'
notes         TEXT
is_active     BOOLEAN default true
created_at    TIMESTAMPTZ
updated_at    TIMESTAMPTZ

Dados seed: 8 serviços padrão

──────────────────────────────────────────────────
3. shelf_products  (insumos de referência)
──────────────────────────────────────────────────
id            UUID PK
category_id   UUID FK → service_categories.id
name          VARCHAR(150) NOT NULL
description   TEXT
unit          VARCHAR(20) default 'm2'
avg_price     DECIMAL(10,2) NOT NULL
supplier_name VARCHAR(150)   -- nullable
supplier_url  VARCHAR
technical_specs TEXT
is_active     BOOLEAN default true
created_at    TIMESTAMPTZ
updated_at    TIMESTAMPTZ

Dados seed: 5 produtos (Vinil, Lona, ACM, PVC, Tinta UV)

──────────────────────────────────────────────────
4. profiles  (extensão do auth.users)
──────────────────────────────────────────────────
id            UUID PK FK → auth.users.id ON DELETE CASCADE
name          VARCHAR(150)
phone         VARCHAR(20)
city          VARCHAR(100)
state         CHAR(2)
role          VARCHAR(30) CHECK IN ('buyer','supplier','admin') default 'buyer'
created_at    TIMESTAMPTZ

Trigger: on_auth_user_created — cria perfil automaticamente no signup
         usando raw_user_meta_data->>'name' e ->>'role'

──────────────────────────────────────────────────
5. supplier_profiles
──────────────────────────────────────────────────
id            UUID PK
user_id       UUID FK → profiles.id ON DELETE CASCADE
company_name  VARCHAR(150) NOT NULL
cnpj          VARCHAR(18)
logo_url      VARCHAR
description   TEXT
services      TEXT[]
cities_served TEXT[]
rating_avg    DECIMAL(3,2) default 0
total_reviews INT default 0
is_premium    BOOLEAN default false
is_active     BOOLEAN default true
created_at    TIMESTAMPTZ

──────────────────────────────────────────────────
6. service_requests  (pedidos de orçamento)
──────────────────────────────────────────────────
id            UUID PK
buyer_id      UUID FK → profiles.id  -- nullable (pedido anônimo)
buyer_name    VARCHAR(150)
service_type  VARCHAR(100) NOT NULL
category      VARCHAR(100)
material      VARCHAR(100)
width_m       DECIMAL(8,2)   -- armazenado em metros (input em CM)
height_m      DECIMAL(8,2)
quantity      INT default 1
city          VARCHAR(100) NOT NULL
state         CHAR(2) NOT NULL
deadline_days INT default 7
description   TEXT
file_url      VARCHAR
status        ENUM('open','reviewing','closed','cancelled') default 'open'
expires_at    TIMESTAMPTZ default now() + interval '7 days'
created_at    TIMESTAMPTZ

──────────────────────────────────────────────────
7. proposals
──────────────────────────────────────────────────
id            UUID PK
request_id    UUID FK → service_requests.id ON DELETE CASCADE
supplier_id   UUID FK → supplier_profiles.id ON DELETE CASCADE
price_total   DECIMAL(10,2) NOT NULL
delivery_days INT NOT NULL
payment_terms VARCHAR(200)
notes         TEXT
is_featured   BOOLEAN default false
status        ENUM('pending','accepted','rejected') default 'pending'
created_at    TIMESTAMPTZ
UNIQUE(request_id, supplier_id)  -- 1 proposta por fornecedor por pedido

──────────────────────────────────────────────────
8. reviews
──────────────────────────────────────────────────
id            UUID PK
proposal_id   UUID FK → proposals.id ON DELETE CASCADE
reviewer_id   UUID FK → profiles.id ON DELETE SET NULL
supplier_id   UUID FK → supplier_profiles.id ON DELETE CASCADE
rating        SMALLINT CHECK(1-5) NOT NULL
comment       TEXT
created_at    TIMESTAMPTZ

──────────────────────────────────────────────────
9. shelf_estimates  (log de estimativas geradas)
──────────────────────────────────────────────────
id                  UUID PK
request_id          UUID FK → service_requests.id ON DELETE CASCADE
standard_service_id UUID FK → standard_services.id ON DELETE SET NULL
calculated_price    DECIMAL(10,2)
formula_used        VARCHAR(30)
inputs_snapshot     JSONB
created_at          TIMESTAMPTZ

=== RELAÇÕES ===

auth.users ──────────────────────── profiles (1:1, trigger)
profiles ────────────────────────── supplier_profiles (1:1)
profiles ────────────────────────── service_requests (1:N, buyer)
service_categories ──────────────── standard_services (1:N)
service_categories ──────────────── shelf_products (1:N)
service_requests ────────────────── proposals (1:N)
supplier_profiles ───────────────── proposals (1:N)
proposals ───────────────────────── reviews (1:1)

=== RLS (Row Level Security) ===

Leitura pública:
  - service_categories (todas ativas)
  - standard_services (is_active = true)
  - shelf_products (is_active = true)
  - supplier_profiles (is_active = true)
  - service_requests (status = 'open')
  - proposals, reviews (todos)

Autenticado:
  - profiles: INSERT/UPDATE/SELECT próprio (auth.uid() = id)
  - service_requests: INSERT público, UPDATE pelo dono
  - proposals: INSERT autenticado, UPDATE pelo dono do supplier
  - supplier_profiles: INSERT/UPDATE pelo dono (user_id = auth.uid())
